Aucune dépendance externe : la connexion s'appuie sur `imaplib` de la
bibliothèque standard et le module ne déclare pas `external_dependencies`. Il
s'installe comme un module Odoo standard, avec `mail` en dépendance.

Les réponses passent par le serveur sortant d'Odoo : sans serveur sortant
configuré, l'assistant de réponse ne peut pas envoyer (voir Configuration).
Aucun ordre d'installation particulier.
