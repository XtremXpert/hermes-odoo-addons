Courriels IMAP

Relie une boîte courriel IMAP à Odoo : le module crée des fiches de compte (serveur, port, SSL, identifiants), découvre les dossiers de la boîte et rapatrie les en-têtes des derniers messages.

La synchronisation, réservée aux gestionnaires, rapatrie au plus 50 messages par dossier et ignore ceux déjà connus par leur Message-ID. Le corps d’un message n’est téléchargé qu’à l’ouverture (Lire) ; le message est alors marqué lu sur le serveur. Une réponse part par le serveur sortant d’Odoo, avec les en-têtes In-Reply-To et References, pour que le fil reste complet chez le destinataire.

Chaque courriel rapatrié peut être ancré au contact Odoo reconnu par son adresse d’expédition, dans le fil du contact. La connexion s’appuie sur imaplib de la bibliothèque standard : aucune dépendance Python externe.

Configuration

Le module n’ajoute pas d’écran de réglages : la connexion se règle sur chaque fiche de compte, dans Courriels > Comptes.

Deux groupes sont déclarés et s’attribuent dans l’onglet Droits d’accès de la fiche usager :

  • IMAP — Lecture : lecture des comptes, dossiers et messages ;
  • IMAP — Gestionnaire : en plus, création et suppression des comptes, test de connexion et synchronisation.

Le mot de passe IMAP est porté par la fiche du compte ; son champ n’est visible que du groupe IMAP — Gestionnaire et il est stocké dans la base Odoo.

L’envoi des réponses passe par le serveur sortant configuré dans Odoo (Réglages > Technique > Courriel > Serveurs sortants, en mode développeur) : sans serveur sortant, l’assistant de réponse ne peut pas envoyer.

Usage

Pour utiliser ce module, il faut :

  1. Attribuer les groupes IMAP — Gestionnaire ou IMAP — Lecture aux usagers concernés, dans l’onglet Droits d’accès de la fiche usager.
  2. Créer le compte dans Courriels > Comptes (menu réservé au groupe gestionnaire) : nom, propriétaire, serveur IMAP, port (993 par défaut), SSL, utilisateur et mot de passe.
  3. Vérifier la connexion avec Tester sur la fiche du compte, puis lancer Synchroniser : les dossiers sont créés, puis les en-têtes des derniers messages de chaque dossier sont rapatriés.
  4. Consulter Courriels > Boîte pour les messages rapatriés, avec le contact reconnu, et Courriels > Dossiers pour les dossiers découverts et leur nombre de non-lus.

Sur un message, Lire télécharge le corps puis le marque lu sur le serveur ; Marquer lu pose le drapeau sur le serveur sans télécharger le corps ; Répondre ouvre un assistant pré-rempli dont l’envoi passe par le serveur sortant configuré dans Odoo.

La synchronisation est réservée au groupe IMAP — Gestionnaire. Un usager non gestionnaire ne voit que les comptes dont il est propriétaire ; le gestionnaire voit tous les comptes.
