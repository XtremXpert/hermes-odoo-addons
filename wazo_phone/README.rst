Connecteur **Wazo Platform**, module d'**un tenant** Wazo.

- connexion au serveur Wazo (URL, jeton d'API, tenant) par les réglages
  ;
- création d'utilisateurs Wazo (ligne SIP, poste, endpoint, messagerie
  vocale) depuis un contact Odoo ;
- création de groupes d'appel (*ring groups*) : poste pris dans la plage
  des groupes du contexte, membres rattachés par utilisateur Wazo et
  ordonnés par priorité de sonnerie ;
- inventaire des postes du contexte : rattachements, postes orphelins,
  correspondance avec les fiches Odoo ;
- journal d'appels synchronisé depuis ``wazo-call-logd`` (tâche
  planifiée et bouton manuel), statistiques d'appels par contact ;
- softphone WebRTC dans Odoo (moteurs sip.js et SDK Wazo).

Les **plages d'extensions** sont lues dans Wazo (``contextnumbers``) au
lieu d'être recopiées : un poste hors plage, d'un autre type, ou déjà en
service, est refusé **avant** toute écriture distante.

Configuration
=============

1. Inscrire les utilisateurs aux groupes du module : les menus sont
   rangés derrière eux et l'administrateur n'y est **pas** d'office. Le
   groupe « Téléphonie Wazo : Gestionnaire » implique « Utilisateur ».
2. Dans Réglages → **Téléphonie Wazo**, renseigner l'URL du serveur, le
   jeton d'API et le tenant, puis tester la connexion. Côté tenant, le
   jeton est le **jeton de tenant** fabriqué par ``wazo_server``.

Softphone dans le navigateur (pont voip)
----------------------------------------

La section « Pont softphone » des réglages n'apparaît que si le module
``voip`` d'Enterprise est installé et que le serveur Wazo expose le
transport ``wss`` :

- **Softphone (voip)** : active le pont (paramètre
  ``wazo.softphone_enabled``, vrai par défaut) ; les champs suivants
  sont masqués quand il est faux.
- **URL WebSocket (wss)** : ``wazo.ws_url`` ; à défaut, l'URL est
  dérivée de ``wazo.url`` (voie native v3, endpoint
  ``/api/asterisk/ws``).
- **Domaine SIP (PBX)** : ``wazo.pbx_domain``, utilisé dans les URI SIP
  ; « asterisk » par défaut.
- **Créer le provider et propager les identifiants** : crée ou met à
  jour le provider « Wazo » et réapplique les identifiants SIP des
  utilisateurs synchronisés.

Usage
=====

Pour utiliser ce module, il faut :

1. Attribuer le groupe **Téléphonie Wazo : Utilisateur** (ou
   *Gestionnaire*) à l'usager, et lier son compte Odoo à un poste Wazo
   synchronisé.
2. Ouvrir *Téléphonie Wazo* > *Tableau de bord* : indicateurs sur 7, 30
   ou 90 jours (appels, manqués, taux de réponse entrant, temps d'appel)
   pour son poste ; un gestionnaire voit en plus la section *Équipe* et
   la répartition par poste.
3. Consulter *Téléphonie Wazo* > *Journal d'appels* (fourni par
   ``wazo_tenant``) : sens, appelant, destination, appel répondu, durée
   et contact reconnu. Le journal est alimenté par la synchronisation,
   manuelle ou planifiée, pas en temps réel.
4. Si l'administrateur a activé le softphone, ouvrir le panneau par
   l'icône téléphone de la barre système : composer un numéro et cliquer
   **Appeler**, répondre avec **Répondre**, terminer avec
   **Raccrocher**. L'onglet *Journal* du panneau liste les appels
   récents.
5. Cliquer **Appeler** sur un numéro dans n'importe quel champ téléphone
   d'Odoo (click-to-call) : l'appel part par le softphone si l'usager a
   un poste Wazo configuré, sinon par le lien ``tel:`` du navigateur.
6. En fin d'appel, une note est déposée sur la fiche du contact reconnu
   ; un appel entrant manqué crée une activité « Appel » et une
   notification.

Le pont softphone (activation, moteur, URL WebSocket, domaine SIP) se
règle dans *Réglages* > *Téléphonie Wazo*.
