Après l'installation, un humain crée une clé API pour le compte `hermes_n3` (fiche de l'utilisateur, onglet Sécurité du compte) et la range dans le coffre. Sa valeur ne doit jamais être écrite dans un dépôt.

Pour réactiver l'agent sur une copie neutralisée, il faut réactiver le compte et lui créer une nouvelle clé.
