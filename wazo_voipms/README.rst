Pont entre **Wazo** (PBX, module ``wazo_phone``) et **VoIP.ms** (trunk
RTC, module ``voipms_sms``).

Deux directions :

- **Sortant** — ``wazo.voipms.trunk`` provisionne un sous-compte SIP
  chez VoIP.ms, un endpoint+trunk+outcall côté Wazo. Les usagers
  composent ``<préfixe><numéro>`` pour sortir par ce trunk.
- **Entrant** — un DID VoIP.ms (``voipms.did``) peut être routé vers une
  destination Wazo (utilisateur ou groupe d'appel) : le module crée
  l'``incall`` dans ``from-extern`` puis bascule le routage VoIP.ms en
  ``sip:<DID>@<hôte Wazo>``.

Configuration
=============

Prérequis :

- ``wazo.url`` + ``wazo.api_key`` configurés (module ``wazo_phone``) ;
- ``voipms.api_username`` + ``voipms.api_token`` configurés (module
  ``voipms_sms``) ;
- le serveur Wazo joignable en SIP par VoIP.ms (port 5060/5061 public)
  pour le routage entrant.

Menu **Téléphonie Wazo → Trunks VoIP.ms** pour le trunk sortant ;
l'onglet **Pont Wazo** apparaît sur les fiches DID.
