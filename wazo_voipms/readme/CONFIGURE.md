Prérequis :

* ``wazo.url`` + ``wazo.api_key`` configurés (module ``wazo_phone``) ;
* ``voipms.api_username`` + ``voipms.api_token`` configurés (module
  ``voipms_sms``) ;
* le serveur Wazo joignable en SIP par VoIP.ms (port 5060/5061 public)
  pour le routage entrant.

Menu **Téléphonie Wazo → Trunks VoIP.ms** pour le trunk sortant ;
l'onglet **Pont Wazo** apparaît sur les fiches DID.
