Ce module n'a pas d'impact sur l'interface utilisateur.

C'est pour l'instant un squelette : il n'ajoute ni menu, ni vue, ni réglage. Les outils
d'entretien de l'instance (état du serveur, relais SMTP, quarantaine globale…) viendront
s'y ajouter ; l'exploitation d'un tenant reste dans `mailcow_tenant`.
