(xtremxpert.ca) : entretien de l'instance, suivi des versions,
préparation des accès remis aux exploitants de tenants.

Squelette pour l'instant — les outils d'entretien (état de l'instance,
relais SMTP, quarantaine globale…) viendront s'y ajouter. Les
exploitants de tenants (diverse-cite.com, …) n'ont pas à l'installer :
leurs outils vivent dans ``mailcow_tenant``.
