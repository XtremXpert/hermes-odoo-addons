# Notes de ce dépôt

`AGENTS.md` dit **comment travailler ici**. Ces notes gardent ce qui a été
**mesuré** : les expériences, leurs résultats, et ce qu'on en a conclu — pour
qu'on n'ait pas à les refaire, ni à les croire sur parole.

| Note | Ce qu'elle établit |
|---|---|
| [version-et-migrations.md](version-et-migrations.md) | pourquoi une version à cinq segments rend une migration silencieusement inerte, et quelle forme est le remède |
| [mesures-qui-trompent.md](mesures-qui-trompent.md) | huit instruments qui ont menti pendant la restructuration, et le contrôle qui les remplace |

Une note n'entre ici que si elle porte une **mesure** : une commande, son
résultat, et la règle qu'on en tire. Ce qui n'est qu'une convention de travail va
dans `AGENTS.md`.
