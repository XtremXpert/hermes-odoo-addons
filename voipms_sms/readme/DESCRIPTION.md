Boîte d'envoi de **SMS** par l'API REST de **VoIP.ms** (`api_username` / `api_token`).

- gestion des DID (numéros d'émetteur) du compte VoIP.ms ;
- boîte d'envoi avec segmentation automatique des messages longs (150 caractères,
  format `n/N`) ;
- synchronisation des DID depuis le serveur ;
- configuration de la connexion (utilisateur et jeton) dans les réglages.
